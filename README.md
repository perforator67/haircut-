# КОНТУР — сайт-визитка барбершопа

Одностраничный сайт для вымышленного премиального барбершопа «КОНТУР» (Санкт-Петербург). Портфолио-проект: чистые HTML/CSS/JS, без сборки и фреймворков.

## Как открыть

Просто откройте `index.html` двойным кликом — сайт полностью статический и не требует сервера, сборки или установки пакетов. Из внешних ресурсов подключены только шрифты Google Fonts (через `<link>`).

## Что внутри

```
index.html        — разметка, все секции и модальное окно записи
css/style.css     — все стили: переменные, адаптивная сетка, анимации
js/main.js        — шапка при скролле, мобильное меню, появление секций
                     при скролле (IntersectionObserver), модалка записи
assets/logo.svg      — монограмма-логотип
assets/favicon.svg   — фавикон
assets/og-image.svg  — изображение для Open Graph (превью в соцсетях)
```

Содержание сайта: шапка с навигацией, hero-экран, блок «О нас» с цифрами,
услуги и цены (8 позиций), три мастера, преимущества, контакты с
телефоном/адресом/часами работы и стилизованной SVG-схемой проезда,
футер. Кнопка «Записаться» открывает модальное окно с формой — бэкенда
нет, отправка имитируется на клиенте (это демонстрационный проект).

## Концепция

- **Название:** КОНТУР — слово напрямую отсылает к барберскому делу
  (чёткий контур стрижки/бороды) и к характеру бренда: точность, форма,
  уверенность.
- **Слоган:** «Чёткая линия. Уверенный образ.»
- **Логотип:** монограмма «К», где диагонали буквы одновременно читаются
  как раскрытые лезвия ножниц с осью-«винтом» в точке пересечения —
  один знак, два смысла.
- **Палитра:** глубокий графит/уголь + приглушённое золото-латунь,
  с двумя светлыми секциями (off-white) для контраста и ритма —
  по заданной палитре проекта.
- **Шрифты:** Oswald (заголовки, капс, широкий трекинг) + Inter
  (текст и интерфейс) — связка «плотный акцидентный гротеск + нейтральный
  гротеск», характерная для премиальных барбершопов.

## Референсы

Перед вёрсткой посмотрел несколько современных барбершоп-лендингов:

1. **CUT EMPYRE** (кейс на Framer/Contra, дизайнер Raheel Farooq) —
   кинематографичный hero на чёрно-золотой палитре, крупная типографика,
   CTA, ориентированные на запись. Взял отсюда идею контрастного
   крупного заголовка в hero и «тихой» золотой акцентной линии вместо
   ярких элементов.
2. **Golden Gate Barbershop** (showcase на Webflow) — тёмная тема с
   золотыми акцентами, карточки мастеров, понятный блок с часами
   работы и записью. Позаимствовал общий ритм секций: hero → о нас →
   услуги → мастера → контакты, и саму идею карточек мастеров с
   коротким «спеком» вместо длинных биографий.
3. **BladeCraft** (HTML-шаблон, WrapMarket) — премиальный тёмно-золотой
   стиль, липкая кнопка записи, прайс-лист с разделителями. Отсюда —
   приём с «пунктирными точками» между названием услуги и ценой
   (классический вид меню) и идея sticky-шапки с кнопкой «Записаться».

Ничего не копировалось пиксель-в-пиксель: цвета, типографика, логотип,
иллюстрации, тексты и вся разметка — собственная интерпретация в рамках
заданной палитры и композиции проекта.

## Доступность и адаптивность

- Семантическая разметка (`header`, `main`, `section`, `footer`),
  `lang="ru"`, `alt`/`aria-label` у интерактивных и декоративных элементов.
- Видимый `:focus-visible` на всех интерактивных элементах.
- Модальное окно записи — `role="dialog"`, `aria-modal`, базовый focus-trap,
  закрытие по `Esc` и клику по оверлею.
- Адаптив mobile-first: от 360px и выше, бургер-меню на узких экранах,
  отсутствие горизонтального скролла.
- Анимации уважают `prefers-reduced-motion`.
